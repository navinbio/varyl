# VARYL

VARYL is a Windows desktop chemical structure editor and combinatorial molecule-library builder developed and published by Pentose LLC.

Visit the [VARYL website](https://navinbio.github.io/varyl/) to download the Version 1.0.3 unrestricted 30-day trial. New users start the trial with one click; no activation code, email, license file, or payment information is required. A Pentose-issued license is required after the trial ends.

Generated structures must be reviewed by a qualified chemist before scientific or operational use.
