# VARYL

VARYL is a Windows desktop chemical structure editor and combinatorial molecule-library builder developed and published by Pentose LLC.

Visit the [VARYL website](https://navinbio.github.io/varyl/) to download the Version 1.0 30-day trial. A device-specific activation file issued by Pentose LLC is required.

Generated structures must be reviewed by a qualified chemist before scientific or operational use.
