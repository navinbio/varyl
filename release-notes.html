VARYL

Version 1.0.0

Release notes

What is included

Offline structure drawing, RDKit validation, scaffold and fragment libraries, arm and SCR enumeration, canonical SMILES, duplicate removal, calculated molecular properties, recovery and backups, plus Excel, CSV, SDF, and CDXML exports.

VARYL prevents a second application instance from opening and competing for the same local control queue.

Installation notes

Generated structures require review by a qualified chemist. The installer is not yet code-signed, so Windows may display an unknown-publisher warning. Projects and permanent libraries remain in the Documents folder when the application is upgraded or removed.
