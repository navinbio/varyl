Version 1.0.2 trial

Release notes

What is included

Offline structure drawing, RDKit validation, scaffold and fragment libraries, arm and SCR enumeration, canonical SMILES, duplicate removal, calculated molecular properties, recovery and backups, plus Excel, CSV, SDF, and CDXML exports.

VARYL requires a Pentose-issued, digitally signed activation file. Trial activations are fixed to one Windows computer for 30 days and cannot be restarted by reinstalling.

Activation improvements

The activation window now provides Copy Activation Request and Copy Email Address. Paste the copied request into an email and send it to navinbio@gmail.com, then load the license file you receive.

Installation notes

Generated structures require review by a qualified chemist. The installer is not yet code-signed, so Windows may display an unknown-publisher warning.
